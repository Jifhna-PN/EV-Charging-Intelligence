# EV CHARGING INTELLIGENCE

**Power BI Dashboard | EV Charging Network Performance & Demand Analysis**

## Project Overview

EV Charging Intelligence is an interactive Power BI dashboard designed to analyze electric vehicle charging transactions and identify patterns in charging demand, user behavior, and infrastructure utilization.

The project transforms raw charging transaction data into meaningful insights through data cleaning, data modeling, DAX calculations, and interactive visualizations.

## Project Objectives

- Analyze overall EV charging demand and transaction patterns.
- Identify peak charging hours and high-demand days.
- Understand charging behavior across different locations.
- Evaluate charger and infrastructure utilization.
- Discover trends in energy consumption and charging duration.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization

## Dataset

**Dataset Name:** A Dataset for Multi-Faceted Analysis of Electric Vehicle Charging Transactions.

**Source:** Figshare

[Access the original dataset](https://figshare.com/articles/dataset/A_dataset_for_multi-faceted_analysis_of_electric_vehicle_charging_transactions/22495141)

The dataset contains EV charging transaction details, including:

- User ID
- Charger ID
- Charger Company and Type
- Location
- Charging Start and End Time
- Charging Duration
- Energy Consumed (kWh)
- Charging Demand

## Project Workflow

1. Data Collection
2. Data Cleaning and Transformation using Power Query
3. Data Modeling using Fact and Dimension Tables
4. DAX Measures and KPI Development
5. Interactive Dashboard Design
6. Business Insights and Analysis

## Key Insights

- Identified Thursday as the highest-demand day.
- Observed peak charging activity around 5 PM – 7 PM.
- Apartment locations showed the highest concentration of charging activity.
- September 2022 recorded the highest monthly activity.
- Analyzed charging sessions, average demand, and energy consumption.

## Dashboard Features

- Overall charging demand and session KPIs
- Charging activity by day and hour
- Monthly charging trends
- Location-based demand analysis
- Charging duration analysis
- Charger-level performance analysis
